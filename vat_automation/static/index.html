准备注册资料

资料文档只在服务器本机解析，不调用外部 AI 或云端 API。身份证明按账号隔离保存在权限 0700 的私有临时目录，程序退出时删除。

1. 解析客户资料文档

支持 PDF、DOCX、XLSX、TXT、JSON、CSV、TSV，最大 12MB。建议使用“字段名: 值”格式。

    2. HMRC 登录（收验证码）

    以上仅用于登录 HMRC / 创建新的 Government Gateway 账号，不会写进申请，也不出现在 Check your answers。手机号国家默认 China，“是否英国手机号”默认 No。
    登录信息会保存在本机私有存储里（0600），下次启动留空即用。

    新建的 Government Gateway User ID：。保存后下次直接用 Government Gateway 登录，不用再手动填。

    3. 三份身份证明

    必须一次选择正好 3 份，每份最大 25MB。文件仅供后续 HMRC 页面自动上传。
    高级设置
    新客户选 Create new sign in details：程序会自动建 Government Gateway 账号（需要邮箱、手机、密码）。客户已有账号才选 Government Gateway：需要 Gateway User ID 和密码。

    最终核对

    请逐项核对下方与 HMRC 核对页一致的内容。确认操作不可撤销：确认后程序会点击 HMRC 的提交按钮，正式提交申请。
