## 2. 启动与日常检查

在项目根目录执行：

```bash
# 英国 VAT 网页程序
.venv/bin/vat-web --config vat-config.flow.json
# 地址：http://127.0.0.1:8765
```

销售交付工作台是另一个入口：

```bash
.venv/bin/vat-bench --uk-vat-config vat-config.flow.json
# 地址：http://127.0.0.1:8770
```

使用已有账号登录；无账号时按启动终端的初始化提示创建管理员。前台启动用 `Ctrl+C` 停止。启动前可用 `lsof -nP -iTCP:8765 -sTCP:LISTEN` 检查端口，已有服务则直接访问。不要在客户任务运行中重启服务。

新环境安装步骤见 `README.md`。Web 使用 `vat-config.flow.json`，命令行字面量配置使用 `vat-config.example.json` 的副本，两者不要混用。

## 4. 推荐的数据处理方式

保留已有字段，最小范围扩展：

| 信息 | 字段 | 来源 |
| --- | --- | --- |
| 公司注册国家／地区 | `company_registration_country` | 公司注册资料 |
| 公司注册地址国家／地区 | `country` | 公司地址及人工确认 |
| 个人居住国家／地区 | `home_country` | 居住地址及人工确认 |
| 海外税号所属国家／地区 | `company_registration_country` | 当前业务使用公司注册号作为税号，国家取公司注册地 |
| 验证码手机号国家／地区 | `HMRC_MFA_PHONE_COUNTRY` | 实际手机号及人工选择 |

- 国家识别顺序：该字段明确填写的国家 → 该地址中明确出现的国家 → 留空请用户补充。来源冲突时提示确认，不相互覆盖。公司地址没有可识别国家或省市信息时沿用公司注册地；居住地址不使用该兜底。税号国家按已确认业务规则使用公司注册地。
- 使用一套共享的国家／地区映射，兼容中文、英文及代码，如中国／China／CN、香港／Hong Kong／HK、爱尔兰／Ireland／IE。香港单独映射到 HMRC 的 Hong Kong 选项。填写时匹配当页实际选项；无法唯一匹配就停止。无需为此引入外部 AI 服务。
- 国家代码只在国家字段或明确地址片段中识别，避免把普通地址中的短词误当国家；其他国家同样允许人工选择，不只支持上述三地。
- 海外税号直接使用公司注册号，有号码时选择 Yes；保留字符串及前导零。不另设税号有无选择，缺号时停止待补充。
- 手机号国家选择改造暂缓：新建账号主要使用自动管理 Authenticator，无需短信手机号；保留原有短信备用方式，不增加国家确认步骤。
- 地址保留原文并允许人工编辑结构化字段。支持爱尔兰字母数字邮编，以及表单允许邮编为空的情况；不生成虚假邮编。现有地址字段长度保护继续保留，不能静默截断。
- 新字段需贯通解析别名、`FIELD_DEFINITIONS`、`VAT_REGISTRATION_FIELD_KEYS`、资料袋、两个网页入口及工作台保存流程；旧资料缺字段时显示待补充。

## 5. 后续实施顺序

### P0：消除国家默认值误填

1. 增加共享国家归一化逻辑，移除个人地址与缺失国家的 China 默认值；已有明确的 China 资料仍正常处理。
2. 删除流程表的全局国家兜底；地址页继续用 `doc:home`、`doc:business`。税号国家页改读公司注册地，同步 JSON 与 `screenshot_flow.py`。
3. 保留“海外税号填写公司注册号”的业务规则，不拆分字段或增加税号有无选项。
4. 地址国家的必要校验放在共用后端，覆盖首次启动、工作台启动、暂停修改后继续；前端同步提示。手机号国家选择按用户要求暂不实施。
5. 更新旧测试中依赖错误默认值的断言，并补充下节案例。运行记录应能定位缺失字段，但不记录凭据或完整客户资料。

完成标准：国家按各自资料传递；缺失、冲突或未确认的信息不会被默认值掩盖；首次启动和继续运行均受校验保护。

### P1：完善国际地址和资料确认

完善中英文地址拆分、爱尔兰邮编、可选字段校验和公司号码标签。对于不能可靠拆分的地址保留原文，请用户修正；人工修正后须重新确认。更改国家或清空字段后，要验证资料袋旧值确实失效，防止继续运行时沿用旧资料。

### P2：验证不同公司类型的流程分支

通过本地模拟页面和经授权的人工联调检查 HMRC 分支。记录适用公司类型与未覆盖页面，遇到未知流程停止。固定营业额、SIC、英国／非英国公司分支属于另一层业务规则，单独核对，不能因国家识别改造而直接宣称全面兼容。

| 案例 | 预期 |
| --- | --- |
